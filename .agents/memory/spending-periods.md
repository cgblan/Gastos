---
name: Períodos de gasto
description: Cómo deben alinearse las métricas de Gastos rápidos con el cobro.
---

El mes de seguimiento de gastos no necesariamente coincide con el mes natural. El usuario cobra en días variables y necesita poder establecer el inicio de cada período para que los totales reflejen ese ciclo.

**Why:** el usuario indicó que el inicio puede variar cada mes según el día de cobro.

**How to apply:** usar una fecha de inicio explícita para las métricas del período actual y permitir rangos de fechas personalizados para el análisis histórico.
